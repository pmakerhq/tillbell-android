# Bridge contract

JSON Schemas (draft 2020-12) and examples of the Tillbell bridge contract, copied unchanged from
[tillbell-rails v0.1.1](https://github.com/pmakerhq/tillbell-rails/tree/v0.1.1/contract)
(commit `66f864f6a88a9b1de31d1cea13983b230059e0db`). The contract has not changed since commit
`38401d9980504ec4e11d65cdd149cee7e89a29c9` (pull request pmakerhq/tillbell-rails#10), where it
was first copied from.

The unit tests validate every reply the component builds against these schemas. To update the
contract, copy the `contract/` directory of a newer tillbell-rails release here and update the
version above.
